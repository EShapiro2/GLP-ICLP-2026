\section{Grassroots Definitions}\label{appendix:grassroots-defs}

This appendix recalls from~\cite{lewis2026volitional} the definitions of protocols and of the grassroots property referenced in Section~\ref{sec:grassroots}, and the condition under which a protocol defined by transactions is oblivious, and extends the latter to a protocol in which the person acts.

%------------------------------------------------------------------------------
\subsection{Protocols and the Grassroots Property}
%------------------------------------------------------------------------------

A protocol is a family of multiagent transition systems, one for each finite set of agents $P \subset \Pi$, sharing an underlying set of local states with a designated initial state.

\begin{definition}[Local-States Function~\cite{lewis2026volitional}]\label{definition:local-states-function}
A \temph{local-states function} $S: 2^\Pi \to 2^\calS$ maps every finite set of agents $P \subset \Pi$ to a set of local states $S(P) \subset \calS$ that includes $s_0$ and satisfies $P \subset P' \implies S(P) \subset S(P')$.
\end{definition}

Given a local-states function $S$, we use $C(P) := S(P)^P$ for configurations over $P$ and $c_0(P) := \{s_0\}^P$ for the initial configuration.

\begin{definition}[Protocol~\cite{lewis2026volitional}]\label{definition:protocol}
A \temph{protocol} $\calF$ over a local-states function $S$ is a family of multiagent transition systems with exactly one transition system $\calF(P) = (C(P), c_0(P), T(P), {\sim(P)})$ for every finite $P \subset \Pi$.
\end{definition}

A \emph{correct} run of a transition system is safe and live (Definition~\ref{def:ts}); the runs here are safe by construction, so correctness coincides with liveness.

\begin{lemma}[Extension~\cite{lewis2026volitional}]\label{lemma:extension}
Every finite safe run of a transition system is a prefix of a correct run of it.
\end{lemma}

Informally, in a grassroots protocol two disjoint groups of agents can each operate independently---their interleaved correct runs are correct runs of the combined system---yet the combined system offers genuinely new behaviours that neither group could produce on its own. To define this formally, we first define the interleaving of runs of two disjoint groups.

\begin{definition}[Interleaving~\cite{lewis2026volitional}]\label{def:interleaving}
Let $P, P' \subset \Pi$ be disjoint nonempty sets of agents, $r = c_0, c_1, \ldots$ a run of $\calF(P)$, and $r' = d_0, d_1, \ldots$ a run of $\calF(P')$. An \temph{interleaving} of $r$ and $r'$ is a sequence $e_0, e_1, \ldots$ of configurations in $C(P \cup P')$ for which there exist non-decreasing sequences of indices $(i_k)_{k \geq 0}$ and $(j_k)_{k \geq 0}$ with $i_0 = j_0 = 0$ such that for every $k \geq 0$:
\begin{enumerate}
\item $(e_k)_p = (c_{i_k})_p$ for every $p \in P$,
\item $(e_k)_q = (d_{j_k})_q$ for every $q \in P'$,
\item if $e_{k+1}$ exists, then exactly one of:
  (a) $i_{k+1} = i_k + 1$ and $j_{k+1} = j_k$ (a $P$-step), or
  (b) $i_{k+1} = i_k$ and $j_{k+1} = j_k + 1$ (a $P'$-step).
\end{enumerate}
Moreover, if $r$ is finite of length $n$ then $i_k = n$ for some $k$, and if $r$ is infinite then for every $m \ge 0$ there is a $k$ with $i_k = m$; likewise for $r'$ and $(j_k)$.
\end{definition}

Note that an interleaving is well-defined: since $P \subset P \cup P'$, the local-states function ensures $S(P) \subset S(P \cup P')$, and similarly for $P'$, so each $e_k$ is a valid configuration in $C(P \cup P')$. Also, $e_0 = c_0(P \cup P')$, since $(e_0)_p = (c_0)_p = s_0$ for all $p \in P$ and $(e_0)_q = (d_0)_q = s_0$ for all $q \in P'$.

\begin{definition}[Interaction, Interactive Run~\cite{lewis2026volitional}]\label{definition:interaction}
Let $Q \subset \Pi$. For a configuration $c$ over $Q$ and $R \subseteq Q$, write $c|_R$ for the restriction of $c$ to $R$. A transition $e \to e'$ of $\calF(Q)$ is an \temph{interaction between} $x \ne y \in Q$ if $e|_{\{x\}} \ne e'|_{\{x\}}$ and $e|_{\{y\}} \ne e'|_{\{y\}}$, and $e|_{\{x\}} \to e'|_{\{x\}}$ is not a transition of $\calF(\{x\})$ or $e|_{\{y\}} \to e'|_{\{y\}}$ is not a transition of $\calF(\{y\})$. It is an \temph{interaction between} disjoint nonempty $P, P' \subseteq Q$ if it is an interaction between some $x \in P$ and some $y \in P'$. A run $\hat r$ of $\calF(Q)$ is \temph{interactive between $P$ and $P'$} if some transition of $\hat r$ is an interaction between them.
\end{definition}

\begin{definition}[Oblivious, Interactive, Grassroots~\cite{lewis2026volitional}]\label{definition:grassroots}
A protocol $\calF$ is:
\begin{enumerate}
\item \temph{oblivious} if for every disjoint nonempty $P, P' \subset \Pi$,
    every interleaving of a correct run of $\calF(P)$ and a correct run of $\calF(P')$ is a correct run of $\calF(P \cup P')$.
\item \temph{interactive} if for every $Q \subset \Pi$ and disjoint nonempty $P, P' \subseteq Q$, every prefix of a correct run of $\calF(Q)$ containing no interaction between $P$ and $P'$ is a prefix of a correct run of $\calF(Q)$ that contains one.
\item \temph{grassroots} if it is oblivious and interactive.
\end{enumerate}
\end{definition}

Being oblivious means that two disjoint groups of agents, each running the protocol independently and correctly, do not interfere with each other: any interleaving of their independent correct runs is a correct run of the combined system. Being interactive means that two disjoint groups that have not interacted can still do so: the combined system has a correct continuation in which one transition engages an agent of each group. In an interleaving, each step changes the local states of agents in only one group; therefore, any transaction whose active participants span both groups yields a step that cannot occur in any interleaving. These definitions are the machine-layer specialisation, without guards, of the volitional grassroots framework of~\cite{lewis2026volitional}.

\subsection{Transactions-Based Protocols}
%------------------------------------------------------------------------------

\begin{definition}[Transactions Over a Local-States Function~\cite{lewis2026volitional}]\label{definition:transactions-lsf}
Let $S$ be a local-states function. A set of transactions $R$ is \temph{over $S$} if every transaction $t \in R$ is a transition over participants $Q$ and local states $S(Q')$ for some $Q \subseteq Q' \subset \Pi$. Given such $R$ and $P \subset \Pi$:
$$R(P) := \{t \in R : t \text{ has participants } Q \subseteq P \text{ and is over } S(Q') \text{ for some } Q' \subseteq P\}$$
\end{definition}

A transaction of agents of $P$ from local states of $P$ may reach a local state of a larger set of agents, as when $p$ adds to its state an agent outside $P$. Such a transaction is in $R(P \cup P')$ and not in $R(P)$, so an interleaving of correct runs of $\calF(P)$ and $\calF(P')$ may owe it a liveness obligation that the run of $\calF(P)$ does not owe~\cite{lewis2026volitional}. It is excluded as follows.

\begin{definition}[Contained~\cite{lewis2026volitional}]\label{definition:contained}
A set of transactions $R$ over a local-states function $S$ is \temph{contained} if for every $P \subset \Pi$, every $t = c \rightarrow c'$ in $R$ with participants $Q \subseteq P$ and $c \in S(P)^Q$ is in $R(P)$.
\end{definition}

\begin{definition}[Transactions-Based Protocol~\cite{lewis2026volitional}]\label{definition:tb-protocol}
Let $S$ be a local-states function and $R$ a set of transactions over $S$, in which distinct transactions have disjoint $P$-closures for every $P \subset \Pi$, with a partial equivalence $\sim$. The \temph{protocol $\calF$ over $R$, $S$, and $\sim$} is defined by $\calF(P) := (C(P), c_0(P), R(P){\uparrow}P, {\sim}{\uparrow}P)$ for each $P \subset \Pi$, where $R(P){\uparrow}P$ and ${\sim}{\uparrow}P$ are the $P$-closures (Definition~\ref{def:closure}) of $R(P)$ and of $\sim$ restricted to $R(P)$.
\end{definition}

Since liveness applies to all classes, any class $[t]$ in $R(P \cup P')/{\sim}$ whose transactions have participants spanning both $P$ and $P'$ could obstruct obliviousness if enabled in an interleaving; so could a class whose transactions have participants in $P$ and that is not a class of $\calF(P)$, which containment excludes.

\begin{proposition}[Obliviousness Condition~\cite{lewis2026volitional}]
\label{proposition:oblivious}
A transactions-based protocol over a contained set of transactions is oblivious provided that for every disjoint nonempty $P, P' \subset \Pi$, no class whose transactions have participants spanning both $P$ and $P'$ is ever enabled in any interleaving of correct runs of $\calF(P)$ and $\calF(P')$.
\end{proposition}

In maGLP the person acts: the Input transaction (Definition~\ref{definition:maGLP}) is the person's, belongs to no class, and may bring into an agent's state the name of an agent outside its group. It is the machine-layer counterpart of a volition change in~\cite{lewis2026volitional}, and is added to a transactions-based protocol as follows.

\begin{definition}[Transactions-Based Protocol with Input]\label{definition:tb-protocol-input}
Let $\calF$ be the protocol over $R$, $S$, and $\sim$, and $I$ a set of unary transactions over $S$, each $t \in I$ over one participant $p$ and $S(Q')$ for some $Q' \ni p$. The \temph{protocol over $R$, $S$, $\sim$ and input $I$} is $\calF^I$ with $\calF^I(P) := (C(P), c_0(P), R(P){\uparrow}P \cup I(P){\uparrow}P, {\sim}{\uparrow}P)$ for each $P \subset \Pi$; a transition of $I(P){\uparrow}P$ is in no class.
\end{definition}

\begin{restatable}[Obliviousness Condition with Input]{proposition}{propObliviousInput}
\label{proposition:oblivious-input}
A transactions-based protocol with input over a contained set of transactions is oblivious provided that for every disjoint nonempty $P, P' \subset \Pi$, no class whose transactions have participants spanning both $P$ and $P'$ is ever enabled in any interleaving of correct runs of $\calF^I(P)$ and $\calF^I(P')$.
\end{restatable}

\begin{restatable}[Transactions-Based Grassroots]{theorem}{thmInteractiveGrassroots}
\label{theorem:interactive-grassroots}
A transactions-based protocol with input that satisfies the condition of Proposition~\ref{proposition:oblivious-input} and is interactive is grassroots.
\end{restatable}
