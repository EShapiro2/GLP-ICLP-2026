\section{Conclusion}\label{section:conclusion}

We have presented GLP, a multiagent, concurrent logic programming language designed for implementing grassroots platforms. The key contributions are:

\begin{enumerate}
\item \textbf{GLP Definition:} We defined GLP as an extension of logic programs with reader/writer variable pairs satisfying the Single-Occurrence (SO) invariant and the Single-Reader/Single-Writer (SRSW) restriction, providing asynchronous communication through term matching rather than unification.

\item \textbf{Multiagent GLP:} We extended GLP to multiple agents using multiagent transition systems with atomic transactions, defining maGLP with Reduce, Communicate, and Cold-call transactions.

\item \textbf{Grassroots Proof:} We proved that maGLP is grassroots, with the Cold-call transaction providing the interactive behaviour.

\item \textbf{Grassroots Social Graph:} We demonstrated the expressiveness of GLP by implementing the grassroots social graph protocol, which serves as the infrastructure layer for other grassroots platforms.
\end{enumerate}

Companion papers extend this work: Shapiro~\cite{shapiro2026types} develops a moded type system for GLP enabling the typing of interactive partial computations, and Shapiro~\cite{shapiro2026implementing} derives a deterministic implementation madGLP from maGLP and proves madGLP grassroots, supporting the Dart/Flutter implementation for smartphone deployment.
